# Пустошь: Ржавый Ручей — демо

2D-изометрическая постапокалиптическая RPG. Чистый HTML5 Canvas + JS, без сборки и зависимостей.

## Запуск
**Windows-сборка:** скачайте архив `Poostosh-vДДММГГ.NNN-win64.zip` со страницы [Releases](https://github.com/egorqqa/poostosh/releases/latest), распакуйте и запустите `Poostosh.exe`.

**Из исходников:**
- `npm install`, затем `npm start` — запуск десктоп-версии;
- или `python tools/serve.py` (или `Запустить игру.bat`) → http://localhost:8123 в браузере.

## Версии и обновления
Версия имеет вид `vДДММГГ.НОМЕР` и показывается в главном меню. Если на GitHub вышел более новый релиз, рядом появляется кнопка **«!»** — она открывает загрузку новой сборки.

Выпуск новой версии:
```
npm run bump          # новая версия в game/js/version.js
npm run build         # локальная сборка dist/Poostosh/Poostosh.exe + zip
git tag vДДММГГ.НОМЕР && git push --tags   # GitHub Actions соберёт релиз
```

## Сетевая игра
- **Подключиться:** главное меню → «Сетевая игра» → IP, порт (по умолчанию 7777), пароль, имя.
- **Свой сервер из игры:** там же «Создать сервер» — игра запустит сервер и подключит вас к нему. Друзьям сообщите IP (показывается в окне) и пароль. Для игры через интернет откройте порт на роутере (TCP).
- **Отдельный сервер:** `Сервер.bat` в папке сборки или `Poostosh.exe --server --port 7777 --password пароль`. Без Windows-сборки: `npm install`, затем `node server/server.js --port 7777 --password пароль`.
- Сервер также раздаёт игру по HTTP: можно играть в браузере по адресу `http://IP:7777`.
- Мир общий: NPC, контейнеры и трупы синхронизируются, бой пошаговый и общий для всех игроков в локации. Состояние мира хранится в `world.json` (у встроенного сервера — в папке данных приложения).
- Чат — клавиша **Enter**. Вторжения на сервере общие: тревога приходит всем, отбиваете отрядом, награда — всем, кто был в поселении. Укрепления поселений тоже общие. Квартира у каждого игрока своя. Персонаж хранится на сервере (`chars.json` рядом с `world.json`): задайте «Пароль персонажа» при подключении — и входите им с любого компьютера. Без пароля персонаж привязан к этому компьютеру.
- Клик по другому игроку: **обмен** (обе стороны выкладывают предметы и крышки и нажимают «Готов») или **приглашение в отряд**. Отряд: панель с ОЗ и местом союзников, их метки на карте мира, 30% опыта союзникам, чат отряда — сообщение с префиксом `/о`.

## Свой сервер в интернете (VPS)
Подойдёт любой VPS с Linux (1 ядро, 512 МБ ОЗУ хватит). Откройте на нём TCP-порт 7777.

**Вариант 1 — Docker:**
```
git clone https://github.com/egorqqa/poostosh.git && cd poostosh
cp deploy/.env.example .env && nano .env        # пароль, название, приветствие, лимит игроков
docker compose up -d --build
```
Мир хранится в томе `poostosh-data` и переживает перезапуски. Обновление: `git pull && docker compose up -d --build`.

**Вариант 2 — без Docker (Ubuntu/Debian, systemd):**
```
curl -fsSL https://raw.githubusercontent.com/egorqqa/poostosh/main/deploy/install.sh | sudo bash
sudo nano /opt/poostosh/.env && sudo systemctl restart poostosh
```
Журнал: `journalctl -u poostosh -f`. Мир — в `/var/lib/poostosh/world.json`.

Настройки сервера (параметры или переменные окружения): `--inv-first`/`INVASION_FIRST_MIN` (минут игрового времени до первого вторжения), `--inv-every`/`INVASION_EVERY_H` (часов между вторжениями, 0 — выключить), `--port`/`PORT`, `--password`/`PASSWORD`, `--name`/`SERVER_NAME`, `--motd`/`MOTD`, `--max`/`MAX_PLAYERS` (по умолчанию 8), `--data`/`DATA_DIR`. Страница состояния: `http://IP:7777/server`, играть в браузере: `http://IP:7777`.

**Список серверов в игре.** В окне «Сетевая игра» показываются серверы из файла [`servers.json`](servers.json) этого репозитория, избранные и недавние — с онлайном, версией и пингом. Чтобы ваш VPS видели все, добавьте его в `servers.json`:
```json
{ "servers": [ { "name": "Пустошь — общий мир", "host": "203.0.113.10", "port": 7777 } ] }
```

## Что есть
- **Характеристики** (Сила, Восприятие, Выносливость, Харизма, Интеллект, Ловкость, Удача) — создание персонажа, 3 профильных навыка.
- **Навыки**: Оружие, Ближний бой, Медицина, Выживание, Красноречие, Торговля, Взлом, Кража, Скрытность. Каждый влияет на механику:
  - Оружие / Ближний бой — шанс попадания;
  - Медицина — эффект аптечек и «Первая помощь»;
  - Выживание — шанс случайных встреч, скорость путешествия, отдых, шанс заметить засаду;
  - Красноречие — реплики-проверки в диалогах;
  - Торговля (+Харизма) — цены;
  - Взлом — запертые ящики (отмычки +20%);
  - Кража — карманные кражи (вес/цена вещи, восприятие жертвы, скрытность);
  - Скрытность — шанс быть замеченным в режиме «Красться», атака из скрытности.
- **Пошаговый бой** с очками действия, шансом попадания, критами, бронёй (КБ/ПУ/СУ), перезарядкой, ИИ врагов.
- **Инвентарь** со слотами оружия и брони, грузоподъёмность (перегруз — нельзя идти).
- **Торговля**, **лут** трупов и контейнеров, **кража**, **взлом**, свидетели преступлений.
- **Уровни и опыт**, очки навыков.
- **Карта мира** (гексы, туман войны, время, отдых, случайные встречи) и 2 локации + генерируемые встречи.
- Задание «Лекарства для Ручья» с несколькими решениями (бой, скрытный взлом, убеждение, подкуп).
- Лёгкие задания в Ржавом Ручье для прокачки: «Долг Тихона», «Инструменты Бориса», «Раненый часовой», «Мародёр у водокачки», «Сухпаёк для Тихона». Над NPC: «!» — есть задание, «?» — можно сдать. Журнал — в окне «Персонаж».
- Зона выхода на карту мира подсвечена зелёным и подписана «ВЫХОД».
- Звук: синтезированные эффекты (выстрелы по типу оружия, удары, шаги, замки, лут, торговля, уровень) и фоновая музыка для каждой локации, карты мира и боя — без внешних файлов (`game/js/audio.js`). Громкость — «Настройки» в главном меню, 🔊 — быстро выключить.
- Обучение для новичка: 10 пошаговых подсказок и стрелка к цели (`game/js/tutorial.js`), отдельная подсказка в первом бою. Отключаются в настройках.
- Быстрые слоты 1–3 у панели оружия, назначаются в инвентаре.
- Мини-карта локации (`game/js/minimap.js`): выход, жители, задания, враги, игроки; клик — идти туда.
- Перки: выбор на каждом чётном уровне (окно «Персонаж»), список — `PERKS` в `data.js`.
- Прицельные выстрелы (голова / руки / ноги) с эффектами: оглушение, выбитое оружие, хромота.
- Мастерская Бориса: патроны, бинты, отмычки, аптечки и броня из хлама (`RECIPES`).
- Карта мира: отметки «!» / «?» / «✔» над местами по заданиям, «не исследовано» для непосещённых мест. Автосохранение при входе в локацию.
- Глава 2 «Нити „З-2“»: карта мира расширена на восток за реку; переправа — Ржавый мост со сборщиками пошлины (заплатить, уговорить, запугать или прорваться); станция «Рассвет» (комендант Вера, радист Кузьма, интендант Палыч), побочное задание «Молчащая антенна»; Объект 9 и его хранилище с полковником Зориным; финал — уничтожить склад «З-2» или забрать ящик (Вере или Сёме). Река на мосту рисуется процедурно (`river` в описании локации).
- Глава 7 «Север»: карта расширена на север; Северный рудник (освободить пленных шахтёров — ключ надсмотрщика или Взлом 45) и Бастион «Сталь» с маршалом Бореем (убедить распустить армию, взорвать арсенал, убить маршала или — если служили Колонне — стать его преемником).
- Глава 8 «Совет пустоши» (финал): Кузьма зовёт на Совет в Ржавый Ручей, во время Совета Ручей штурмует орда «Пепел». Её состав зависит от прежних решений, а союзники из прошлых глав ослабляют штурм. После победы — эпилог о судьбе каждого края и титры, затем свободная игра.
- Улучшение оружия (Борис и свой верстак): оптический прицел (+10% к попаданию, +2 к дальности), увеличенный магазин (×1,5), глушитель (выстрел слышно только рядом, тихая атака из скрытности не поднимает всю округу), заточка холодного оружия (+2 к урону). Метки улучшений видны в названии оружия: [П], [М], [Г], [З].
- Карта мира показывает караваны в пути (значок движется по маршруту, рядом остаток часов) и активные вторжения (красное кольцо и таймер).
- Модели героя с оружием в руках: пистолет, ружьё (обрез и винтовка), автомат. 8 направлений, ходьба, прицеливание и выстрел со вспышкой.
- Ремесло из добычи (Борис и свой верстак): броня из волчьих шкур, хитиновая броня, хитиновый клинок, крысиная похлёбка.
- Совместный караван отряда: лидер предлагает рейс, участники за 15 секунд выбирают вклад, прибыль и потери делятся по долям.
- Глава 6 «Запад»: карта расширена на запад (Великая пустыня — без воды мучает жажда), Оазис с Хранительницей Ясной и Солнечная станция атамана Зноя. Сердечник насоса: договориться о воде, выкупить, украсть со склада или взять станцию штурмом.
- Свои караваны: у Сёмы (Ручей) и Палыча («Рассвет») — маршрут, товар, охрана или личное сопровождение с боем; после главы 6 — дальний путь в Оазис.
- Радтаракан (`радтаракан.png` → `game/assets/chars/roach.png`), размером с крысу: подвалы, аптека, город, рои в пути.
- Тяжело раненые противники (меньше 15% ОЗ) отступают и сбегают с поля боя (кроме боссов и обращённых).
- Таблица лидеров сервера (меню паузы и страница `/server`): вторжения, контракты, караваны, убийства. По умолчанию на сервере до 8 игроков.
- Глава 5 «Юг» (после главы 4, у Кузьмы): карта расширена на юг. После тёмной концовки — «Улей» обращённых с Маткой и сердцем гнезда; иначе — «Южный форт» с остатками Колонны и лейтенантом Ржой (уговорить распустить отряд, взять командование, если вступали в Колонну, или штурм).
- Оборона поселений: у Гвоздя (Ручей) и часовых «Рассвета» — стены (меньше нападающих) и турели (бьют по нападающим каждый раунд), до 3 уровней.
- Улучшения квартиры: самогонный аппарат (самогон из консервов и воды), стойка для брони (подгонка надетой брони до +9 КБ/+3 ПУ), радиоприёмник (новости по прогрессу игры, тревоги о вторжениях).
- Напарники: Лёха, Тихон, комендант Вера (после главы 2) и инженер Лада (после главы 4, лечит героя после каждого боя).
- После финала: вторжения Колонны или обращённых на Ржавый Ручей и «Рассвет» (24 часа на защиту), ежедневные случайные контракты на доске.
- Глава 4 «Обсерватория» (после главы 3, у Кузьмы): лагерь Колонны на севере, пленный инженер Лада, купол с распылителем «З-2». Финалы: отключить или взорвать распылитель, уговорить Гранита уйти, либо (если вступили в Колонну) запустить распылитель — тёмная концовка.
- Своя база: подъезд «Длинного дома» в Старом городе → очистить → «Занять квартиру». В квартире кровать (сон 8 ч, лечение, сохранение), личный схрон и место под верстак (6 хлама + 30 крышек); за своим верстаком крафт без оплаты. Аптеку в Старом городе тоже можно осмотреть изнутри.

- Глава 3 «Стальная Колонна» (после главы 2, у радиста Кузьмы): локация «Старый город» из спрайтов папки `Город` (вырезка фона — `tools/city_cutout.py`, масштаб к росту героя — `CITY` в `tools/build_assets.py`); командор Гранит, Клык (или Шрам, если Клык погиб в главе 1); концовки: сдать Клыка живым/мёртвым, отпустить и солгать, разоблачить Колонну или вступить в неё.
- Контракты отряда: доска на остановке в Ржавом Ручье. Счёт убийств общий для всего отряда, награда — каждому участнику (+15% за бойца).
- Мутантные волки и вожак стаи (`мутантный_волк.png` → `game/assets/chars/wolf.png`): Мёртвый лес к северу от Ручья, волчьи стаи на травяных гексах; задание Сёмы «Шкуры для Сёмы».
- День и ночь: ночью темно (свет у героя и фонарей), враги замечают с меньшего расстояния, стрелять вдаль труднее. В сетевой игре время общее и идёт на сервере.
- Радкрысы — мелкие (вдвое меньше человека) быстрые противники со своей моделью на 8 направлений (`радиоактивная_крыса.png` → `game/assets/chars/rat.png`). Живут в подвале водокачки Ручья, в «Заре» и случайных встречах; задание Михалыча «Крысиная напасть».
- Журнал заданий (J): активные и завершённые задания, кто выдал, текущая цель и отметка цели на карте мира. Меню паузы по Esc.
- Репутация в Ржавом Ручье: растёт за помощь жителям, падает за кражи и убийства; влияет на цены, реплики, лечение у Ирины; «Враг Ручья» — охрана стреляет.
- Напарник: Лёха (после «Раненого часового») или Тихон (после «Сухпайка») идут с вами, сражаются, носят свои вещи. Клик по напарнику — команды и обмен вещами (в одиночной игре).
- Мирные события на карте мира: караван, раненый путник, тайник, заминированная машина, водонос, радиосигнал.
- Анимации боя: вспышка выстрела, отдача, встряска и кровь при попадании, падение тела.
- Сюжет «Тайна карантина „Зари“» (даёт док Ирина): интерьеры — заводоуправление, цех №3 и подземная лаборатория «Заря-2» с заражёнными; две концовки (отдать образцы Ирине или продать Сёме). Входы в здания — через меню объекта («Войти»), выходы из помещений — зелёные зоны «НАРУЖУ»/«НАВЕРХ» (`exits[].to` в описании локации). Стены помещений рисуются процедурно (`drawInterior` в `engine.js`).
- Интерактивные объекты (автобусы, машины, погрузчик, щитки, вагоны, ящики, водонапорные башни и др.): клик — меню «Осмотреть» (опыт за первый осмотр), «Обыскать» (немного лута, больше с Выживанием и Удачей), особые действия с проверкой навыка или характеристики. Описание — `INTERACT` в `game/js/data.js`.
- Локация «Промзона „Заря“» (юго-восток карты): мусорщики, их бригадир и сейф. Задание Бориса «Аккумулятор для Бориса» открывает её на карте.

## Ассеты
Спрайты нарезаются из исходных листов в корне папки скриптом:
```
python tools/build_assets.py
```
Он кладёт результат в `game/assets/` и генерирует `game/js/manifest.js`. Модели героя с оружием собирает `tools/build_guns.py` из листов в папке `оружие/`: подгоняет рост, точку опоры и тон, раскладывает по 8 направлениям. Координаты нарезки и масштаб каждого листа — в начале скрипта (`SHEETS`, `SPRITES`).

## Структура кода (`game/js`)
- `data.js` — характеристики, навыки, предметы, NPC, диалоги, локации, карта мира;
- `rules.js` — формулы (ОЗ, ОД, навыки, цены, проверки), инвентарь;
- `engine.js` — изометрия, отрисовка, поиск пути, эффекты;
- `world.js` — логика локаций: движение, скрытность, кража, взлом, диалоги;
