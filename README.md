# Пустошь: Ржавый Ручей — демо

2D-изометрическая постапокалиптическая RPG. Чистый HTML5 Canvas + JS, без сборки и зависимостей.

## Запуск
**Windows-сборка:** скачайте архив `Poostosh-vДДММГГ.NNN-win64.zip` со страницы [Releases](https://github.com/egorqqa/poostosh/releases/latest), распакуйте и запустите `Poostosh.exe`.

**Из исходников:**
- `npm install`, затем `npm start` — запуск десктоп-версии;
- или `python tools/serve.py` (или `Запустить игру.bat`) → http://localhost:8123 в браузере.

## Версии и обновления
Версия имеет вид `vДДММГГ.НОМЕР` и показывается в главном меню. Если на GitHub вышел более новый релиз, рядом появляется кнопка **«!»** — она открывает загрузку новой сборки.

Выпуск новой версии:
```
npm run bump          # новая версия в game/js/version.js
npm run build         # локальная сборка dist/Poostosh/Poostosh.exe + zip
git tag vДДММГГ.НОМЕР && git push --tags   # GitHub Actions соберёт релиз
```

## Сетевая игра
- **Подключиться:** главное меню → «Сетевая игра» → IP, порт (по умолчанию 7777), пароль, имя.
- **Свой сервер из игры:** там же «Создать сервер» — игра запустит сервер и подключит вас к нему. Друзьям сообщите IP (показывается в окне) и пароль. Для игры через интернет откройте порт на роутере (TCP).
- **Отдельный сервер:** `Сервер.bat` в папке сборки или `Poostosh.exe --server --port 7777 --password пароль`. Без Windows-сборки: `npm install`, затем `node server/server.js --port 7777 --password пароль`.
- Сервер также раздаёт игру по HTTP: можно играть в браузере по адресу `http://IP:7777`.
- Мир общий: NPC, контейнеры и трупы синхронизируются, бой пошаговый и общий для всех игроков в локации. Состояние мира хранится в `world.json` (у встроенного сервера — в папке данных приложения).
- Чат — клавиша **Enter**. Персонаж сохраняется отдельно для каждого сервера.

## Что есть
- **Характеристики** (Сила, Восприятие, Выносливость, Харизма, Интеллект, Ловкость, Удача) — создание персонажа, 3 профильных навыка.
- **Навыки**: Оружие, Ближний бой, Медицина, Выживание, Красноречие, Торговля, Взлом, Кража, Скрытность. Каждый влияет на механику:
  - Оружие / Ближний бой — шанс попадания;
  - Медицина — эффект аптечек и «Первая помощь»;
  - Выживание — шанс случайных встреч, скорость путешествия, отдых, шанс заметить засаду;
  - Красноречие — реплики-проверки в диалогах;
  - Торговля (+Харизма) — цены;
  - Взлом — запертые ящики (отмычки +20%);
  - Кража — карманные кражи (вес/цена вещи, восприятие жертвы, скрытность);
  - Скрытность — шанс быть замеченным в режиме «Красться», атака из скрытности.
- **Пошаговый бой** с очками действия, шансом попадания, критами, бронёй (КБ/ПУ/СУ), перезарядкой, ИИ врагов.
- **Инвентарь** со слотами оружия и брони, грузоподъёмность (перегруз — нельзя идти).
- **Торговля**, **лут** трупов и контейнеров, **кража**, **взлом**, свидетели преступлений.
- **Уровни и опыт**, очки навыков.
- **Карта мира** (гексы, туман войны, время, отдых, случайные встречи) и 2 локации + генерируемые встречи.
- Задание «Лекарства для Ручья» с несколькими решениями (бой, скрытный взлом, убеждение, подкуп).
- Лёгкие задания в Ржавом Ручье для прокачки: «Долг Тихона», «Инструменты Бориса», «Раненый часовой», «Мародёр у водокачки», «Сухпаёк для Тихона». Над NPC: «!» — есть задание, «?» — можно сдать. Журнал — в окне «Персонаж».
- Зона выхода на карту мира подсвечена зелёным и подписана «ВЫХОД».
- Звук: синтезированные эффекты (выстрелы по типу оружия, удары, шаги, замки, лут, торговля, уровень) и фоновая музыка для каждой локации, карты мира и боя — без внешних файлов (`game/js/audio.js`). Громкость — «Настройки» в главном меню, 🔊 — быстро выключить.
- Обучение для новичка: 10 пошаговых подсказок и стрелка к цели (`game/js/tutorial.js`), отдельная подсказка в первом бою. Отключаются в настройках.
- Быстрые слоты 1–3 у панели оружия, назначаются в инвентаре.
- Мини-карта локации (`game/js/minimap.js`): выход, жители, задания, враги, игроки; клик — идти туда.
- Интерактивные объекты (автобусы, машины, погрузчик, щитки, вагоны, ящики, водонапорные башни и др.): клик — меню «Осмотреть» (опыт за первый осмотр), «Обыскать» (немного лута, больше с Выживанием и Удачей), особые действия с проверкой навыка или характеристики. Описание — `INTERACT` в `game/js/data.js`.
- Локация «Промзона „Заря“» (юго-восток карты): мусорщики, их бригадир и сейф. Задание Бориса «Аккумулятор для Бориса» открывает её на карте.

## Ассеты
Спрайты нарезаются из исходных листов в корне папки скриптом:
```
python tools/build_assets.py
```
Он кладёт результат в `game/assets/` и генерирует `game/js/manifest.js`. Координаты нарезки и масштаб каждого листа — в начале скрипта (`SHEETS`, `SPRITES`).

## Структура кода (`game/js`)
- `data.js` — характеристики, навыки, предметы, NPC, диалоги, локации, карта мира;
- `rules.js` — формулы (ОЗ, ОД, навыки, цены, проверки), инвентарь;
- `engine.js` — изометрия, отрисовка, поиск пути, эффекты;
- `world.js` — логика локаций: движение, скрытность, кража, взлом, диалоги;
- `combat.js` — пошаговый бой и ИИ;
- `ui.js` — нижняя панель и окна; `worldmap.js` — карта мира; `main.js` — состояние, ввод, сохранения;
- `net.js` — сетевой клиент; `server/server.js` — игровой сервер; `desktop/` — оболочка Windows-сборки.
