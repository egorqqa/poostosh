**Новое главное меню**

- **Фон главного меню** — одна из четырёх заставок, выбирается случайно при каждом запуске игры. Картинка растягивается на весь экран с сохранением пропорций и плавно проявляется.
- **Меню в правом нижнем углу** в виде металлической панели с заклёпками. У каждой кнопки индикатор: зелёный — основное действие, красный — остальные, при наведении загорается зелёным.
- **Кнопка «Продолжить»** появляется, если есть сохранение.
- **Кнопка «Выход»** есть всегда: в программе для Windows закрывает игру, в браузере закрывает вкладку или подсказывает, как выйти.
- **Версия игры** показана в левом нижнем углу.
- **На маленьких экранах** меню становится компактнее.
